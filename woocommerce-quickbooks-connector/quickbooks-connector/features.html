Features

Every feature below is available from Webkul WC Addons → WC Quick Book Connector in your WordPress admin.

Connection & Onboarding

  • Guided four-step Setup Wizard (Welcome → Environment → Credentials → Ready) with Skip option
  • Sandbox / Development and Live / Production environment modes
  • OAuth 2.0 authorization (recommended) with legacy OAuth 1.0 selectable
  • One-click Connect with QuickBooks — Company ID, access token, and refresh token fetched automatically
  • Built-in connection test that verifies credentials before saving them
  • Connection dashboard with status badges, masked credentials, and token status
  • Edit credentials, Re-run Setup Wizard, and Delete Credentials (with confirmation) at any time
  • Copyable Redirect URIs for your Intuit Developer app

Customer Sync

  • Export Customers from WooCommerce to QuickBooks (selected rows)
  • Import Customers from QuickBooks into WooCommerce
  • Per-customer mapping dropdown with live QuickBooks customer search
  • Clear a customer's mapping without touching the customer record
  • Search customers by email; adjustable rows per page

Product Sync

  • Export Products to QuickBooks — variable products export each variation
  • Two-step import: Import List stages QuickBooks items, Create Products builds them in WooCommerce
  • Batch-size control (3–30) with resumable import position
  • Duplicate-SKU protection with a live "products skipped" counter
  • Real-time export on product save, filtered by product category
  • Real-time import via QuickBooks webhooks, filtered by QuickBooks category
  • Product image sync in either direction
  • Per-product mapping dropdown, Clear Mapping, and sync-source badge
  • Optional export of zero-price products

Order Sync & Accounting

  • Export Orders manually from the Orders tab
  • Auto Export Orders when an order reaches a chosen status (Pending, Processing, On hold, Completed, or All)
  • Export orders as Sales Receipt, Invoice, Estimate, or Credit Memo
  • Void the QuickBooks transaction when a WooCommerce order is cancelled
  • Refund receipts created automatically for WooCommerce refunds
  • Choose the QuickBooks transaction date (order date, paid date, complete date, or sync date)
  • Choose the line-item description (product name, description, or short description)
  • Payment reference number from order number or transaction ID
  • Statement memo, service date, print status, and skip-country options
  • Default QuickBooks Class and Department for exported orders
  • Sync status pill per order, search by order ID, and POS / WooCommerce source filter
  • QuickBooks column on the WooCommerce Orders screen showing export status at a glance

Payments, Fees & Deposits

  • Map every enabled WooCommerce gateway to a QuickBooks payment method
  • Per-gateway Advanced Configuration:
    • Payment sync timing — when the order is received or completed
    • Target QuickBooks bank account and invoice due days (0–100)
    • Transaction fee syncing with a QuickBooks VAT rate and expense account
    • Stripe-specific: record fees as an Expense or Journal Entry with a payee supplier
    • Batch bank deposits from Undeposited Funds on a weekly schedule (day + hour)
    • Per-gateway QuickBooks class and department

Tax Mapping

  • Map each WooCommerce tax class to a QuickBooks tax name
  • Default tax code for records without a specific mapping
  • Clear a tax mapping at any time

Automation & Housekeeping

  • QuickBooks webhooks (items, invoices, bills, payments) processed asynchronously
  • Background schedules keep recently changed QuickBooks items updated in WooCommerce
  • Weekly per-gateway deposit schedules
  • Detailed activity logs in WooCommerce → Status → Logs
  • Need Help? menu with user guide, video, and support desk links

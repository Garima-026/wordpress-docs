Configuration

Base Plugin Configuration

Since this is an add-on, please ensure you have fully configured the base plugin first. For detailed instructions on setting up your eBay account and core connector settings, refer to the WooCommerce eBay Connector Documentation.

After installing the module, the user can make the configurations by navigating through WooCommerce eBay Connector > eBay Account List > Action.

eBay Account List

The store admin can import products by selecting Import All from the dropdown and clicking Import From eBay in the Products section (under Manage Account).

Likewise, the admin will navigate to the Settings > Item Compatibility sub-tab to enable the import of compatible vehicles during product import by selecting Yes for "Import Compatible Items During Product Import".

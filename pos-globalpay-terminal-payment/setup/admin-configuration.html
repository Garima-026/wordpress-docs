Admin Gateway Configuration

The POS Global Payment Terminal Gateway is configured and managed directly within the native WooCommerce Checkout settings tab. This gives store administrators centralized control over payment gateway enablement, default pre-selection, payment titles, customer descriptions, test mode toggles, and Globalpay merchant account credentials.

Accessing Gateway Settings

  1. Log into the WordPress Administration Dashboard.
  2. Navigate to WooCommerce → Settings in the left sidebar menu.
  3. Click on the Payments tab.
  4. Locate POS Global Payment Terminal Gateway in the payment providers list and click Manage (or click the gateway title link).

Gateway Settings Breakdown

Clicking Manage opens the gateway administration form:

WordPress Plugins List Settings Link

For convenience, the plugin registers a direct settings shortcut on the main WordPress Plugins screen:

  1. Navigate to Plugins → Installed Plugins.
  2. Locate POS Globalpay Terminal Payment for WooCommerce.
  3. Click Settings to navigate directly to the gateway configuration page (admin.php?page=wc-settings&tab=checkout&section=wkposglobal_payterminal_payment_terminal).

Note: After making any configuration changes, click Save changes at the bottom of the form. Changes immediately update active POS cashier sessions upon panel refresh.

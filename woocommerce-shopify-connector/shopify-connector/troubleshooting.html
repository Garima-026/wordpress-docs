Troubleshooting

Symptoms, verified causes, and fixes for the situations merchants hit most often. When in doubt, the Analytics Dashboard's error table and the WooCommerce logs (WooCommerce → Status → Logs, sources beginning with WooCommerce Shopify Connector) are your best starting points.

Connection problems

"Please Enter Correct Details." when saving an account. Shopify rejected the credentials. Check that the domain is the bare *.myshopify.com host (no https://), the token or Client ID/Secret belong to that store, and the app is installed with sufficient scopes. Then try again.

"Account already exists ." when adding a store. Either the store name is already used by another connection or the same Shopify shop is already connected. Open the existing account instead, or choose a different store name.

"Invalid OAuth state" after returning from Shopify. The authorization link was stale or reused. Start again from Add Account and complete the Shopify approval in one go.

Import problems

"Create Imported Products" is disabled / says products are not available. Phase 1 hasn't been run. Select Import Product first, then create. The same pattern applies to orders, customers, pages, and coupons.

Products were skipped during import.

  • "Product(s) skipped due to category not mapped" — your Products to Import setting is Only mapped categories product, and these products belong to unmapped collections. Map the collections or switch the setting to All products.
  • "Product ID(s) were not found on Shopify and skipped" — a typo in the comma-separated ID list.

Orders were imported but not created.

  • "not Created due to product unavailability so please import products." — import the ordered products first, then create the orders.
  • "not Created due to email not available." — the Shopify order has no customer email; such orders are skipped.

An import seems stuck or a second import won't start. Only one product import can run at a time ("Another product import is in process." / PRODUCT_IMPORT_BLOCKED in the dashboard). Wait for the running job; background queues that stall are restarted automatically within a few minutes.

Images are missing on imported products. Image downloads run after product creation — the counter under the progress bar shows how many are left. Very large images (over 25 MB) are rejected. IMAGE_DOWNLOAD_FAILED in the error table means Shopify's CDN couldn't be reached for that file; run Update From Shopify on the product to retry.

Export problems

"Order(s) Already Exported" / "Product Already Exported". The record is already linked to Shopify. To push newer changes on a product, use Bulk actions → Update To Shopify instead of Export. For orders that existed on both sides before you installed the connector, use Map Old Orders.

"Products are not updated due to unexported on Shopify." You ran Update To Shopify on products that were never exported. Export them first.

PRODUCT_EXPORT_ERROR in the dashboard. Verify the Select Shop Location setting in General Configuration — inventory is written to that location — plus the product's data and your API credentials.

Real-time sync problems

Changes on Shopify never reach WooCommerce. Work through, in order:

  1. Account Settings → Webhooks — are the five webhooks listed? If not, select Generate Webhooks. "Shopify token is invalid" here means the account credentials need to be refreshed.
  2. General Configuration — is Product Auto-Sync set to a direction that includes Shopify → WooCommerce? Are Auto Import Product / Auto Import Order enabled if you expect new records?
  3. Is your site publicly reachable over HTTPS? Webhooks cannot reach localhost or password-protected staging sites.
  4. Check the field lists under Real-Time Sync – Fields to Update — a deselected field is intentionally never updated.

WooCommerce product edits don't appear on Shopify.Product Auto-Sync must be WooCommerce To Shopify or Both Way, and the product must already be exported (or auto-exported via the Export Product Rule).

API_RATE_LIMIT errors during large syncs. Shopify throttled the connector. Space out big manual imports/exports and let the background queue drain before starting another batch.

Customers not receiving (or receiving duplicate) order emails

By design, WooCommerce's order emails are suppressed for imported Shopify orders. If you want WooCommerce to email those customers, set Import Orders Re-Send Email to Enable in General Configuration.

Still stuck?

Collect the error code from the Analytics error table and the matching entries from WooCommerce → Status → Logs, then contact Webkul support with your plugin version (4.0.0) and a description of the sync operation that failed.

Features Spotlight

The Tranzila Payment for WooCommerce POS addon provides key features to securely integrate, configure, and manage credit card transactions at physical Point of Sale checkouts. Here is a detailed spotlight on its core capabilities.

1. Multi-Outlet Terminal Configuration

  • Isolated Outlets Settings: Define separate payment credentials for each outlet individually under Point of Sale > Outlets > Edit Outlet.
  • Direct Revenue Routing: By mapping unique supplier accounts to each outlet, transaction revenue is directly deposited into the correct store bank account.
  • Credentials Lock: Securely store terminal passwords and identifiers to prevent unauthorized tampering by cashiers or clerks.

2. Advanced Terminal Field Mapping

The plugin supports key terminal configuration fields required by the Tranzila payment gateway:

Config FieldPurpose / Use CaseDefault Values
POS IDUnique terminal identifier registered with TranzilaEmpty (Must match hardware sticker)
Supplier NameTranzila account supplier identifiertranzilap (Standard test account)
Company NameBrand name displayed on receipt printoutsCustom text field
Transaction ModeThe explicit transaction mode (A = Standard immediate charge, V = Token capture, N = J2 Verification/Auth, K = Tokenize only)A
Credit TypeDefines how credit cards are billed (Regular vs. Installments)Regular Credit

3. Custom POS Gateway Styling

  • Custom Titles: Define a user-friendly label (e.g. "Card Terminal" or "Tranzila Card Reader") that is clear to cashiers.
  • Toggle Status: Quickly enable or disable the gateway globally from the POS Payment settings panel.

[!IMPORTANT] WooCommerce POS Dependency: Tranzila Payment for WooCommerce POS is an addon extension. It requires the core POS for WooCommerce plugin by Webkul to be installed, active, and licensed on your WordPress installation to function.

[!Note] This plugin currently supports only trademode: A and credtype: 1 in the Tranzila payment gateway.

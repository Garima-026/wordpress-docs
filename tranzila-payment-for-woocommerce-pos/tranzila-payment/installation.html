Installation Guide

Setting up the Tranzila Payment for WooCommerce POS addon requires installing and activating the extension on your WordPress instance alongside the WooCommerce POS core plugin.

1. System Requirements

Before installation, ensure your environment meets the following conditions:

  • WordPress: Version 5.0 or higher.
  • WooCommerce: Version 5.0 or higher.
  • POS for WooCommerce (Webkul): Active, licensed, and configured. Documentation & Info.
  • PHP: Version 7.4 or higher.
  • Tranzila Account: An active merchant terminal account with access to API endpoints.

2. Installing the WordPress Plugin

Method 1: WordPress Admin Dashboard (Recommended)

Step 1: Access Plugin Installation

  1. Log in to your WordPress Admin Panel.
  2. Navigate to: Plugins → Add New.
  3. Click the Upload Plugin button at the top of the page.

Step 2: Upload the Plugin

  1. Click the Choose File button.
  2. Select the downloaded plugin ZIP file (e.g., tranzila-payment-for-woocommerce-pos.zip).
  3. Click Install Now.

Step 3: Activate the Plugin

  1. After successful installation, click Activate Plugin.
  2. Wait for the activation confirmation message to display in your WordPress plugin dashboard.

Method 2: FTP Installation (Alternative)

Step 1: Prepare Files

  1. Unzip the downloaded plugin package.
  2. Extract the tranzila-payment-for-woocommerce-pos folder.

Step 2: Upload via FTP

  1. Connect to your server via FTP/SFTP client.
  2. Navigate to the WordPress plugins directory: /wp-content/plugins/.
  3. Upload the extracted plugin directory to this folder.

Step 3: Activate

  1. Go to your WordPress Admin → Plugins.
  2. Find Tranzila Payment for WooCommerce POS in the list.
  3. Click Activate.

3. Post-Installation Checks

To verify that the plugin has installed successfully:

  • Clear your WordPress site cache if you use caching plugins (e.g., W3 Total Cache or WP Super Cache).
  • Navigate to Point of Sale → Settings → Payment and confirm that Tranzila Terminal is now listed in the payment method table.
  • Navigate to Point of Sale → Outlets, edit an outlet, check the payment methods dropdown, select Tranzila Terminal, and verify that the "Tranzila Payment Terminal Settings" input block is injected.

[!WARNING] WooCommerce POS Dependency: If you activate this plugin and see error notices in your WordPress dashboard, ensure that Webkul's POS for WooCommerce plugin is installed and activated. The addon will gracefully disable its registration hooks if its core dependency is missing.

# Introduction

<a class="doc-image-link" href="./assets/dashboard.webp"><img src="./assets/dashboard.webp" alt="Admin Panel" /></a>


The **WooCommerce Multi Vendor Marketplace plugin** is a powerful solution designed to transform a standard WooCommerce store into a fully functional multi-vendor marketplace.

With this plugin, you can allow **multiple independent vendors** to register, create their own shops, upload products, manage orders, and track earnings – all from a dedicated vendor dashboard.

This enables you to build marketplaces similar to:

- Amazon
- Flipkart
- Etsy
- eBay

---

## What does this plugin do?

This plugin converts your WooCommerce store into a **multi-seller platform** where:

- Each vendor gets a **separate profile page**
- Vendors can **add & manage products**
- Vendors can **process orders**
- Vendors can **track sales & transactions**
- Vendors can **communicate with admin**
- Admin has **full control over marketplace**

---

## Vendor Capabilities

Once registered, vendors get access to a **frontend dashboard** where they can:

- Add new products
- Edit existing products
- Delete products
- View product listings
- Track sales performance
- View transactions
- Manage orders
- Print invoices
- Update profile information
- Change passwords
- Ask questions to admin

<a class="doc-image-link" href="./assets/general-settings.webp"><img src="./assets/general-settings.webp" alt="Admin Panel" /></a>

---

## Admin Capabilities

Marketplace owners (admins) can:

- Manage vendor list
- Manage product list
- Approve or disapprove vendors
- Approve or disapprove vendor products
- Assign products to vendors
- Set **different commission rates** for each vendor
- Enable or disable **auto vendor approval**
- Enable or disable **auto product publish**
- Control all marketplace settings

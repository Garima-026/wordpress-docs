# Vendor Transaction Management

<a class="doc-image-link" href="./assets/admin-transaction.webp"><img src="./assets/admin-transaction.webp" alt="Seller Transactions" /></a>

The **Vendor Transaction Management** section allows vendors to track payments received from the admin for completed orders where the admin has collected payments from buyers.

---

## Access Transactions

- Vendors can access transactions from the **Vendor Dashboard**.
- This section displays all transactions processed by the admin for vendor orders.

<a class="doc-image-link" href="./assets/seller-transactions.webp"><img src="./assets/seller-transactions.webp" alt="Seller Transactions" /></a>

---

## Transaction Overview

Vendors can view the following transaction-related details:

- **Total Earning** – Total amount earned from completed orders
- **Total Withdrawal** – Total amount already withdrawn
- **Total Pending** – Amount pending for withdrawal
- **Total Refunded** – Total refunded amount
- **Last Withdrawal** – Details of the most recent withdrawal
- **Minimum Withdrawal Amount** – Minimum balance required to request a withdrawal

---

## Create a Withdrawal Request

- Click on the **Withdrawal** button to initiate a withdrawal request.
- Vendor is redirected to the **Withdrawal Request** page.

<a class="doc-image-link" href="./assets/webkul-woocommerce-marketplace-withdrawal.webp"><img src="./assets/webkul-woocommerce-marketplace-withdrawal.webp" alt="Withdrawal Page" /></a>

---

## Withdrawal Management

From the withdrawal page, vendors can:

- View available **withdrawal payment methods**
- Set a **default withdrawal method**
- Check **recent withdrawal requests**

To request a new withdrawal:

- Click on **Request Withdrawal**


<a class="doc-image-link" href="./assets/vendor-create-withdrawal-request.webp"><img src="./assets/vendor-create-withdrawal-request.webp" alt="Create Withdrawal Request" /></a>

---

## Submit Withdrawal Request

- Enter the required withdrawal details.
- Click on **Submit Request** to send the withdrawal request to the admin.

---

## View Transaction Details

- Vendors can click on the **View** option for any transaction.
- This displays:
  - Vendor’s earned amount
  - Admin commission for the order

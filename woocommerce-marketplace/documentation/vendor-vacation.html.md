# Vacation Mode

The **Vacation Mode** allows vendors to temporarily close their store when they are unavailable. When enabled, the storefront displays a vacation notice with the vendor's custom message and blocks customer purchases.

---

## Enabling Vacation Mode

Vendors can schedule a vacation directly from their Vendor Dashboard.

To view current or past vacations, vendors can navigate to the Vacation section to see a sortable list of their vacations.

<a class="doc-image-link" href="./assets/vacation-list.png"><img src="./assets/vacation-list.png" alt="Vacation List" /></a>

### Adding a Vacation

To schedule a new vacation, click on the **Add Vacation** button. Vendors can set the start and end dates, and provide a custom vacation message that will be displayed to customers on the storefront.

<a class="doc-image-link" href="./assets/add-vacation.png"><img src="./assets/add-vacation.png" alt="Add Vacation" /></a>

### Editing a Vacation

Vendors can update an upcoming or ongoing vacation by editing the dates or the display message.

<a class="doc-image-link" href="./assets/edit-vacation.png"><img src="./assets/edit-vacation.png" alt="Edit Vacation" /></a>

---

## Admin Controls for Vacation Mode

Admins have full control over the Vacation Mode feature:
- Enable or disable the vacation feature globally.
- Edit a specific vendor's vacation.
- Bulk enable, disable, or delete vacations from a sortable list in the admin panel.
- Configure settings and endpoint options for the vacation menu.

# Customer Order Placement

This guide explains the **customer order placement process** in the WooCommerce Marketplace and highlights how **seller information is displayed** at different stages.

<a class="doc-image-link" href="./assets/customer-order-placement.webp"><img src="./assets/customer-order-placement.webp" alt="Customer Order Placement" /></a>

---

## Seller Discovery on Storefront

Before placing an order, customers can identify and choose products from specific sellers.

### Seller Filter on Product Listing Page

- Customers can filter products based on **seller/vendor** on the shop or listing page.
- This helps customers find products from a preferred seller easily.
- Seller-based filtering improves product discovery in a multi-vendor marketplace.

<a class="doc-image-link" href="./assets/vendor-filter.png"><img src="./assets/vendor-filter.png" alt="seller Filter" /></a>

---

## Seller Information on Product Page

- Each product page displays **seller information** when the product belongs to a vendor.
- Seller details may include:
  - Seller name
  - Seller store link
- Customers can click the seller name to visit the **seller profile page**.

---

## Steps to Place an Order

### 1. Add Product to Cart
- Customer selects the desired product from the storefront.
- Clicks **Add to Cart**.

<a class="doc-image-link" href="./assets/add-to-cart.webp"><img src="./assets/add-to-cart.webp" alt="Add to Cart" /></a>

---

### 2. View Cart

- After adding products, the customer can view the **cart page**.
- Seller name is displayed for each product added to the cart.
- Customers can easily identify which seller each product belongs to.

<a class="doc-image-link" href="./assets/product-added-cart-block.webp"><img src="./assets/product-added-cart-block.webp" alt="Product Added to Cart" /></a>

---

### 3. Proceed to Checkout

- Click **Proceed to Checkout** to navigate to the checkout page.
- Checkout blocks display:
  - Order summary
  - Billing details
  - Shipping details
- Seller information remains visible for vendor products.

<a class="doc-image-link" href="./assets/product-checkout-block.webp"><img src="./assets/product-checkout-block.webp" alt="Checkout Page" /></a>

---

### 4. Order Confirmation

- After successful order placement, the **Order Received** page is displayed.
- Order details include:
  - Ordered products
  - Total amount
  - Shipping information
  - **Seller name for each product**

<a class="doc-image-link" href="./assets/order-received.webp"><img src="./assets/order-received.webp" alt="Order Received" /></a>

---

## Seller Visibility on Order Details Page

- Customers can view seller information from:
  - **My Account → Orders**
  - Order detail page
- Seller name is displayed against each product in the order.
- This ensures transparency in multi-vendor order fulfillment.

---

## Notes

- The order placement process works for both **admin products** and **vendor products**.
- Seller-related information is displayed consistently across:
  - Product listing page
  - Product page
  - Cart page
  - Checkout page
  - Order confirmation and order details page
- This enhances trust and clarity for customers shopping in a multi-vendor marketplace.

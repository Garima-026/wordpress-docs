# Vendor Dashboard Menu

<a class="doc-image-link" href="./assets/dashboard.webp"><img src="./assets/dashboard.webp" alt="Dashboard Print" /></a>

The **Vendor Dashboard** allows vendors to manage marketplace activities and access key functionalities similar to the admin panel.

---

## Vendor Dashboard Sections

- **Reports**
  - View quick infographic reports
  - Access recent orders summary
  - Check sales order history
  - Monitor:
    - Lifetime Sales
    - Total Payout
    - Remaining Amount
    - Refunded Amount

- **Order History**
  - View complete order-related history
  - Track orders placed by customers

- **Transaction**
  - View transaction-related details
  - Includes:
    - Transaction ID
    - Date
    - Transaction Amount

- **Notifications**
  - View order-related notifications
  - Receive product-related updates and alerts

- **Shop Followers**
  - Check the list of followers for the vendor shop
  - View customer queries related to the shop

- **My Profile**
  - Manage and update vendor profile information
  - Edit personal and shop-related details

- **Ask To Admin**
  - View queries raised with the admin
  - Track communication and responses from the admin

---

## Purpose

The Vendor Dashboard helps vendors efficiently manage their store, track performance, and communicate with the admin from a single interface.

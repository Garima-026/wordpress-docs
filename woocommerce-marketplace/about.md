# About

This site is the official user documentation for the **WooCommerce Multi-Vendor Marketplace** plugin, published and maintained by Webkul Software.

## About the plugin

WooCommerce Multi-Vendor Marketplace is a WordPress plugin that converts a standard WooCommerce store into a multi-seller marketplace. It lets independent vendors register, open their own shop pages, list and manage products, process their own orders, track earnings, and request payouts, while the store owner keeps administrative control over vendor approval, commission rates, withdrawal rules, and marketplace-wide settings. It is used to build marketplaces comparable in structure to Amazon, Etsy, Flipkart, or eBay on top of WooCommerce.

The plugin is sold through the [Webkul store](https://store.webkul.com/woocommerce-multivendor-marketplace.html) and a working [live demo](https://wpdemo.webkul.com/woocommerce-marketplace/) is available. A large catalogue of add-ons extends it with payment gateways, shipping methods, tax integrations, mobile apps, point of sale, and vendor management features.

## About this documentation

These guides cover installation, configuration, vendor workflows, and administrator workflows for the plugin. They are written for store owners setting up a marketplace and for developers integrating it into an existing WooCommerce site.

The documentation is a static site. Every page is also published as raw markdown for AI agents and automated tools — append `.md` to any page URL, or start from [llms.txt](https://wpdoc.webkul.com/woocommerce-marketplace/llms.txt).

# How do I install and activate the plugin?

Three short steps. For screenshots, see the full [Installation guide](https://wpdoc.webkul.com/woocommerce-marketplace/documentation/installation.html).

## Install

1. In WordPress, go to **Plugins → Add New → Upload Plugin**.
2. Choose the plugin **ZIP** (do not unzip it) and click **Install Now**, then **Activate**.

## Activate your license

1. Go to **Marketplace → Settings**. The activation wizard appears.
2. Enter your **License Key** and click **Activate License**.

## One required step after activating

Go to **Settings → Permalinks**, choose **Post Name**, and save. This prevents 404s on vendor pages. See [Update permalinks](./update-permalinks.html).

::: tip Still need help?
If the license won't activate, see [License activation failed](../troubleshooting/license-activation-failed.html), or [open a ticket](https://webkul.uvdesk.com/).
:::

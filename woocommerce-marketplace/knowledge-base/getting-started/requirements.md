# What are the requirements?

Before installing, confirm your site meets these minimums. Our support team checks these first.

| Requirement | Minimum / Recommended |
|---|---|
| WordPress | 6.7 or higher |
| WooCommerce | 10.0 or higher |
| PHP | 7.4 or higher |
| Memory limit | 256 MB or higher |
| SSL | Enabled (recommended) |

**Where to check:** *WooCommerce → Status → Server environment* shows your PHP version and memory limit; *Dashboard → Updates* shows WordPress and WooCommerce versions.

::: tip Still need help?
A memory limit under 256 MB is the top cause of activation errors. See [Fatal error when activating](../troubleshooting/fatal-error-on-activation.html). Otherwise [open a ticket](https://webkul.uvdesk.com/).
:::

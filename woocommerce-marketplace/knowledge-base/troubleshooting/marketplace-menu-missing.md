# Marketplace menu is missing after activation

You activated the plugin but there's no **Marketplace** item in the WordPress admin sidebar. Usually the plugin isn't fully active or the license step isn't complete.

## Fix

1. Open **Plugins** and confirm both *WooCommerce Multi-Vendor Marketplace* **and** *WooCommerce* are **Active**.
2. Go to **Marketplace → Settings** and finish the license wizard. See [Install & activate](../getting-started/install-and-activate.html).
3. Still nothing? Deactivate and reactivate the plugin, then reload the admin.

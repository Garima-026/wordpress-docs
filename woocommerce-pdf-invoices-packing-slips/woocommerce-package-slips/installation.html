Installation & Getting Started

Getting started with the PDF Invoices & Packing Slips for WooCommerce plugin takes only a few minutes. This guide covers how to install the plugin, activate it, and access the configuration menus.

Method 1: WordPress Admin Dashboard (Recommended)

Step 1: Access Plugin Installation

  1. Log in to your WordPress Admin Panel.
  2. Navigate to: Plugins → Add New Plugin.
  3. Click the Upload Plugin button at the top of the page.

Step 2: Upload the Plugin

  1. Click the Choose File button.
  2. Select the downloaded plugin ZIP file (woo-pdf-invoices-packing-slips.zip).
  3. Click Install Now.

Step 3: Activate the Plugin

  1. After successful installation, click the Activate Plugin button.
  2. Wait for the activation confirmation message.

Method 2: FTP Installation (Alternative)

If you prefer to upload files directly to your server or if your admin dashboard file limits prevent uploads:

Step 1: Prepare Files

  1. Locate the downloaded plugin ZIP file on your computer.
  2. Uncompress/Unzip the package.
  3. Extract the woo-pdf-invoices-packing-slips folder.

Step 2: Upload via FTP

  1. Connect to your web hosting server using your preferred FTP/SFTP client.
  2. Navigate to your WordPress root plugins folder: /wp-content/plugins/.
  3. Upload the entire extracted woo-pdf-invoices-packing-slips folder.

Step 3: Activate

  1. Log in to your WordPress Admin dashboard.
  2. Go to Plugins → Installed Plugins.
  3. Find Woo PDF Invoices & Packing Slips in the list and click Activate.

Post-Installation Checks

Before configuring settings or generating invoices, perform the following validation checks:

  • Clear Caches: If you are using any server-side cache, CDN, or WordPress caching plugins (e.g., WP Rocket, W3 Total Cache), clear your cache to make sure new admin scripts load.
  • Verify Installation: Ensure that the plugin appears under your active plugins list and that no script errors are displayed.
  • Verify System Paths: Ensure your server directory /wp-content/uploads/ has write permissions enabled (755 or 777), as the PDF engine uses this path to temporarily write and compile PDF invoice files.

Accessing the Plugin Menus

Once activated, the plugin adds two main areas to your WooCommerce admin dashboard.

1. The PDF Invoices Document Portal

To see all generated documents, download archives, or filter invoices by date range:

  • Navigate to WooCommerce → PDF Invoices in the WordPress sidebar.
  • Here you can view, filter, and bulk-download generated Invoices, Packing Slips, Proforma Invoices, Credit Notes, and Picking Lists.

2. The Configuration Settings

To configure your document settings, branding, numbering patterns, and templates:

  • Navigate to WooCommerce → Settings → PDF Invoices tab.
  • This tab is divided into sub-sections: General, Numbering, Appearance, Templates, Checkout, and Export & Reset.

Pre-activation Checklist

Before configuring your settings, gather the following details to speed up your setup process:

  • Company Details: Your legal business name, physical street address, and contact information.
  • Branding Assets: A high-resolution copy of your company logo (supported formats: PNG, JPG, or SVG).
  • Tax Information: Your tax office identifier or VAT number.
  • Sequence Prefix: The abbreviation or prefix you want to use for your invoices (e.g., INV-2026-).

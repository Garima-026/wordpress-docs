Features Spotlight

The WooCommerce Print Barcode Labels plugin comes with a wide range of features designed to scale your e-commerce and retail operations. Here is a breakdown of all core features.

1. Visual Drag-and-Drop Label Creator

  • WYSIWYG Workspace: Design labels visually via a modern drag-and-drop React panel.
  • Custom Layout Blocks: Add and arrange:
    • Product Details: Name, price, sale price, SKU, variable attributes.
    • Order Details: Order ID, date, billing/shipping name, total items, totals.
    • Barcode Elements: Configurable dimensions, barcode formats, and visibility toggles for human-readable text.
    • Custom Text blocks: Add static notes, store terms, or branding.
  • Layout Sizing Controls: Set label height, width, margin, columns, rows, and page borders. Supporting custom dimensions for thermal labels, multi-label sheets, and A4 grids.

2. Multi-Format Barcode Engine

The plugin features a robust barcode generator supporting both standard 1D linear barcodes and 2D matrix barcodes:

Barcode TypeFormat StandardPrimary Use Case
CODE1281D High DensityGeneral warehouse sorting & alphanumeric strings
CODE391D Variable LengthIndustrial applications & legacy hardware scanners

UPC-A1D Retail standardStandard retail product labeling (North America)
ISBN1D Book StandardPublishing and bookstore inventory tracking
QR Code2D MatrixMobile lookups, digital menus, coupon links
PDF4172D StackedHeavy data storage, logistics, shipping slips

3. Print Server & Hardware Automation

  • Node-Based Print Daemon: Local server script runs in the background on your OS to manage WebSocket print commands.
  • Zebra ZPL Command Translator: Converts designed canvas images directly into ZPL instructions for instant Zebra label prints.
  • Image Mode Fallback: Print to any desktop laser, inkjet, or non-Zebra thermal printer via standard canvas-to-PNG printing.
  • Auto-Print Hooks: Enable automatic prints upon e-commerce orders, printing baggage or product labels hands-free at checkouts.

4. Bulk Admin Workflows

  • Product Listing Integrations: Select multiple products in your WordPress catalog and trigger bulk barcode generation and PDF exports.
  • Order Slip Prints: Select multiple orders to generate shipping slips or packaging barcodes in one click.
  • Coupon Barcodes: Print barcode vouchers for WooCommerce discounts and hand them to customers in-store.

[!IMPORTANT] Barcode Scanner Compatibility: Most standard laser scanners require at least a 0.25mm barcode bar width (X-dimension) to register scans reliably. Ensure your visual layout gives barcodes enough breathing room without compressing columns.

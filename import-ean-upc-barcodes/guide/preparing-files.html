Preparing the CSV File

If you have purchased real GS1-registered barcodes and want to assign them to your products, you must first prepare a spreadsheet file containing the codes. The plugin supports .csv, .txt, and .xlsx file formats.

There are two distinct modes for importing barcodes: Sequential Pool and Mapped to Products. The structure of your file depends entirely on which mode you intend to use.

Mode 1: Sequential Pool

In this mode, you simply provide a list of barcodes. The plugin will load these barcodes into an available pool. When a product needs a barcode (either during a bulk assignment or when a new product is created), the plugin will take the next available barcode from the top of this list and assign it.

File Structure

Your file should contain only barcodes. It does not need a header row. Every 8 to 14 digit cell the plugin finds in the file will be counted as a valid barcode and added to the pool.

Example Sequential CSV:

195893240212
098234762912
834729103847
293847562910

This mode is perfect if you are just starting out and want to quickly assign random purchased barcodes to your entire catalog without caring which specific product gets which specific barcode.

Mode 2: Mapped to Products

In this mode, you dictate exactly which product receives which barcode. This is essential if your physical products already have specific barcodes printed on their packaging, or if you are migrating data from another system.

File Structure

Your file must have a header row.

  1. The Barcode Column: You must include a column named barcode (aliases like code, ean, upc, or gtin are also accepted).
  2. The Product Identifier Column: You must include either a product_id column or a sku column so the plugin knows which product to target. If both are present, product_id takes priority.

Example Mapped CSV:

product_id,sku,barcode
105,TSHIRT-RED-M,195893240212
106,TSHIRT-RED-L,098234762912
107,TSHIRT-BLU-M,834729103847

When you upload a mapped file, the plugin will immediately write each barcode to its designated product's destination field. It will also record these mapped codes in the pool table as "used" so they feed into duplicate prevention and auditing. Unknown products or SKUs will be safely skipped.

[!NOTE] Sample Files Provided If you are unsure about the formatting, you can download sample files directly from the Import Codes tab in the plugin admin interface. Look for the links to download the sample sequential and sample mapped CSV files.

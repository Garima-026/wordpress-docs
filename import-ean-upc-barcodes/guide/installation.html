Installation

Installing the Import EAN UPC Barcodes plugin follows the standard WordPress plugin installation process.

Requirements

Before you install the plugin, ensure your server meets the following minimum requirements:

  • WordPress: Version 6.5 or higher (Tested up to 6.8)
  • WooCommerce: Version 9.1 or higher (Tested up to 10.4)
  • PHP: 7.4 or higher (8.0+ recommended for best performance)

Uploading the Plugin

  1. Purchase and download the plugin zip file from the Webkul store.

  2. Log into your WordPress Admin Dashboard.

  3. Navigate to Plugins > Add New Plugin in the left-hand sidebar.

  4. Click the Upload Plugin button at the top of the page.

  5. Click Choose File and select the import-ean-upc-barcodes.zip file you downloaded.

  6. Click Install Now.

Activation

  1. Once the installation is complete, click the Activate Plugin button.

  2. Upon successful activation, a new menu item will appear in your WordPress sidebar under Webkul WC Addons > UPC/EAN Codes.

[!TIP] Locating the Menu The plugin settings and import tools are consolidated under a single menu. Look for Webkul WC Addons in your admin sidebar, then click on UPC/EAN Codes.

License Verification

To access the plugin features, you may need to verify your purchase license.

  1. Navigate to Webkul WC Addons > License.
  2. Enter your purchase code or license details provided at the time of purchase.
  3. Save the changes to fully unlock the plugin.

Installation

Before You Start

Make sure your site meets the requirements:

RequirementMinimum
WordPress6.7 (tested up to 7.0)
WooCommerce10.0 (tested up to 11.0), installed and active
PHP7.4 (tested up to 8.4)

The plugin declares WooCommerce as a required plugin — WordPress will not run it without WooCommerce active.

Install From the Admin

  1. Download the plugin ZIP from your Webkul store or CodeCanyon purchase.
  2. In your WordPress admin, go to Plugins → Add Plugin → Upload Plugin.
  3. Choose the icecat-connector-for-woocommerce ZIP and click Install Now.
  4. Click Activate Plugin.

Install via FTP (alternative)

  1. Extract the ZIP on your computer.
  2. Upload the icecat-connector-for-woocommerce folder to /wp-content/plugins/ on your server.
  3. Activate WooCommerce IceCat Connector from Plugins → Installed Plugins.

After Activation

  • You are redirected straight into the Setup Wizard to connect your Icecat account and choose import preferences. Until the wizard is completed (or skipped past), opening the connector page brings the wizard back.
  • A new menu appears: Webkul WC Addons → IceCat Connector.

Bundled submodules

The plugin ships with the Webkul WC Addons framework as bundled submodules. If you ever see the admin notice "Submodules are required for WooCommerce IceCat Connector Module.", the plugin folder is incomplete — re-upload the full ZIP so the modules/wkwc-addons and modules/wk-plugin-updates folders are present.

Features

Every feature below is available from Webkul WC Addons → IceCat Connector in your WordPress admin.

Importing

  • Import products from the Icecat catalog using any of three search methods: Icecat ID, GTIN (EAN/UPC barcode), or Product Code & Brand.
  • Choose the catalog language per import — around 80 languages are available, from English and French to Japanese and Arabic.
  • Review before you import: the connector shows the fetched title, IDs, brand, product code, and short description first; you create the product only when it looks right.
  • Duplicate protection: if a catalog product is already in your store, the connector tells you, links to the existing product, and offers a one-click Update Existing Product instead of creating a copy.
  • Bulk import via CSV — upload a file of Icecat IDs, GTINs, or product codes and import everything in one background run, with live progress and a downloadable failed-items report. Sample CSVs are provided for every format.

Product Content

  • Full product build: title, short description, long description (including the technical specification content), SKU from the manufacturer's product code, GTIN, and release dates.
  • Image galleries: the featured image and all gallery images are downloaded from Icecat into your Media Library.
  • Technical specifications as attributes: Icecat's spec sheet becomes WooCommerce product attributes, shown on the product page's Additional information tab.
  • Image quality control: import High, Medium, or Low resolution images.

Categories

  • Import with the Icecat category — the product's own catalog category is created in WooCommerce and assigned automatically, or
  • Map to your WooCommerce categories — pick one or more existing store categories for the import (products with no selection go to Uncategorized).

Store Controls

  • Product status on creation: Draft, Publish, or Pending Review — your choice applies to every import.
  • Default stock quantity: new products get this quantity with stock management enabled (set 0 to leave stock management off).
  • Background processing: create images and attributes in the background so imports finish fast, or switch to inline processing to have everything ready the moment the product is created.

Keeping Products Current

  • Update Details From IceCat — one button on the product edit page re-fetches the latest catalog data for that product.
  • Replace Details From IceCat — link any existing simple product to an Icecat ID and replace its content with catalog data.
  • Bulk Update — select products in the connector list and update them all from Icecat.
  • Refresh All Products — re-import the latest data for every connected product in the background, with a live progress card and completion notice.

Product Management

  • Dedicated product list with product ID, image, name, Icecat ID, GTIN, brand & code, import date, and status.
  • Search by Icecat ID to find any import instantly.
  • Bulk actions: Delete (with confirmation), Update, Trash, and Product Publish.
  • Direct Icecat link per product — open the product's page on icecat.biz in one click.

Onboarding & Compatibility

  • Guided Setup Wizard with live connection verification — including a check that a supplied Full Icecat App Key really unlocks Full Icecat content.
  • HPOS and cart/checkout blocks compatible; works with WooCommerce 10.0–11.0 and WordPress 6.7–7.0.

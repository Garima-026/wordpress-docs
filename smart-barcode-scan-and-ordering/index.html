Smart Barcode Scan and Ordering

Scan a barcode in the WooCommerce admin to pull up a product or an order, fix stock and prices on the spot, build a counter order, and keep a timestamped record of everything that was scanned.

Start HereView DemoBuy Now

One console for scanning, stock corrections and counter sales

Smart Barcode Scan and Ordering adds a single admin screen where a barcode is all your staff need to find a product, find an order, or ring up a sale.

Scan
Scanner Console
A focused scan box that accepts hardware-scanner input or typed codes, plus a Recent Scans panel showing the last five lookups.
Find
Product & Order Lookup
One code is matched against product ID, SKU, GTIN/UPC/EAN/ISBN, a custom meta field, product name and order ID.
Fix
Inventory Quick Edit
Correct stock quantity, SKU, regular price, sale price, EAN code and the product image without leaving the popup.
Sell
Create Order
Scan items into a cart, attach a customer, fill billing and shipping, calculate shipping, apply a coupon and create a real WooCommerce order.
Picked · Packed · Shipped
Fulfilment Statuses
Three extra WooCommerce order statuses, advanced one stage per scan, with a tracking code required before an order can ship.
Audit
Activity Logs
Every scan, product edit, order edit, order creation and settings change is recorded with a timestamp and the user who did it.
QR
Order QR Labels
Generate, download or print a QR code for any order straight from the WooCommerce order list, one order at a time or in bulk.
Tune
Scanner Settings
Choose which fields a barcode is matched against, turn the scan beep on or off, auto-clear the input, and cap the log history.

What you can do from the console

Each workflow below is documented step by step, with screenshots taken from a live WooCommerce store.

🔍

Scan a product and see everything about it

Scan or type a barcode and the matching product opens in a popup with its image, type, status, SKU, prices, stock level and EAN code — all editable.

Read Product Scanning →
📦

Correct stock during a count

Adjust the stock quantity in the Inventory tab and save. Out-of-stock items are flagged, and the scanner refuses to add them to an order.

Read Inventory Management →
🧾

Pull up an order by scanning it

Scan an order QR label or type the order ID to see the customer, line items, totals breakdown, addresses and notes — and edit the status.

Ring up a counter sale

Attach or register a customer

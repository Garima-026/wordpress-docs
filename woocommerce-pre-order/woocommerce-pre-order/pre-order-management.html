Pre-Order Management (Admin Dashboard)

Store administrators manage pre-order configurations, track customer pre-orders, check waitlists, reply to shopper inquiries, and manually create pre-orders through a central admin dashboard.

Access this workspace by navigating to WooCommerce > Pre-Order List in your WordPress sidebar.

1. Administrative Workspace Tabs

The dashboard is structured into seven tabs to separate key workflows:

A. Pre Order Products

Lists all WooCommerce products and variations currently configured for pre-orders.

  • Information Displayed: Product title, SKU, base price, payment model (Full/Deposit), pre-order price/deposit, quantity limit, availability date, status (Enabled/Disabled).
  • Inline Actions: Toggle Status (Enable/Disable), Edit configuration, Delete.

B. Pre Order List

Tracks every individual pre-order transaction placed by customers.

  • Information Displayed:
    • Order ID: The parent WooCommerce order ID.
    • Customer: Customer name or guest email.
    • Pre-ordered Product: Title of the item.
    • Quantity: Quantity ordered.
    • Remaining Amount: Outstanding balance (zero for full payments).
    • Linked Order: The secondary order ID created for balance payment.
    • Status: Pending, Notified, Completed, or Cancelled.
  • Actions: Send manual balance payment email alerts, cancel order, filter by pre-order status, or search by Order ID.

C. Campaigns

Displays active promotional countdown campaigns scheduled for future releases.

  • Information Displayed: Product name, start date, end date, campaign status, countdown styling.
  • Actions: Add new campaign, edit, delete, or activate.

D. Stock Subscribers (Waitlist)

Tracks shoppers waiting for standard out-of-stock products to be restocked.

  • Information Displayed: Product name, subscriber name, email address, registration date, notification status.
  • Actions: Filter by notification status, or delete subscriber.

E. Enquiries

A dedicated support channel for customer queries regarding pre-order items.

  • Information Displayed: Enquiry ID, Customer email, Subject, Date, Status (Replied/Pending).
  • Actions: Click View to open the threaded message panel and send replies directly from the dashboard.

F. Reports

Provides sales charts and analytical metrics on pre-order campaigns, conversion rates, deposits pending, and total pre-order revenue.

2. Manual Pre-Order Creation

Administrators can manually create a pre-order on behalf of customers (e.g., for phone orders, wholesale clients, or manual overrides).

Step-by-Step Workflow

  1. Navigate to WooCommerce > Pre-Order List and click the Add Pre-Order button at the top of the page.
  2. Select Customer:
    • For registered customers: Search and select their WordPress user account.
    • For guest shoppers: Enter the customer's billing email address.
  3. Choose Product: Choose any product currently configured with active pre-order status.
  4. Configure Details:
    • Quantity: Specify the number of items.
    • Price Mode: Choose whether to charge the configured deposit (partial payment) or the full product price.
  5. Submit Form:
    • Clicking Create Order creates a WooCommerce order containing the pre-order item.
    • The system sets the order status to Pending Payment, records pre-order tags, and lists the transaction in the Pre Order List with the remaining balance calculated.
  6. An invoice is automatically emailed to the customer with checkout instructions.

3. Product Release & Restocking Workflows

When a pre-ordered product becomes available, store owners initiate the release workflow:

How to Release Pre-Ordered Products

  1. Automatic Release: Go to Products, select the item, and change the stock status to In Stock. The system automatically triggers release tasks.
  2. Manual Release: Turn off the Pre-Order Status toggle under the product’s Pre-Order configuration tab. This immediately releases all associated pre-orders.

Processing Payments

  • Stripe Auto-Charge: If active, the system automatically bills the saved card in background batches of 20. If successful, the pre-order updates to Completed.
  • Manual Billing: For other payment options or failed card payments, the system automatically emails the customer an invoice containing a link. The customer has a configured completion window (e.g., 7 days) to pay before the order is flagged.

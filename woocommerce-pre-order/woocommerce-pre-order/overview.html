Technical Overview & Requirements

Before installing and setting up WooCommerce Pre-Order, verify that your server environment meets the minimum standards to ensure optimal database transactions, scheduled cron actions, and payment processing.

System Requirements

To ensure stability, security, and high performance (especially during heavy pre-sale launches), the following stack is recommended:

ComponentMinimum RequirementRecommended
PHP Version7.48.0+
WordPress Version6.77.0+
WooCommerce Version10.010.9+
MySQL Version5.78.0 or MariaDB 10.5
SSL CertificateRequired for paymentsTLS 1.3
WP-Cron / System CronEnabledSystem Cron (every 5-10m)

Core Capabilities & Performance

The plugin is built to be fast, stable, and fully integrated with the WooCommerce storefront:

1. High Performance & Scalability

Unlike standard plugins that slow down your website when managing hundreds of pre-orders, this plugin uses an optimized storage system separate from your primary post database. This prevents website bloat and keeps your shop page loading quickly, even during high-traffic pre-sale campaigns.

2. Payment Flow Flexibility

Support for three key sales models:

  • Full Payment Upfront: Customers pay 100% of the price at checkout. The order is marked as a pre-order and is fulfilled once the product stock becomes available.
  • Partial Payment (Deposit): Customers pay a small upfront deposit (fixed or percentage) to secure their pre-order, and pay the remaining balance later when the product is released.
  • Pay on Arrival: Customers book their pre-orders without any immediate upfront payment, paying the complete order value only when the item is released and ready to ship.

3. Automated Task Scheduler

The system runs background updates to manage active campaign timelines, update countdown timers, send out scheduled stock reminders, and process pre-order balance invoicing automatically.

Compatibility Status

  • High-Performance Order Storage (HPOS): Fully compatible.
  • Cart & Checkout Blocks: Fully compatible. The custom hooks translate pre-order checkout states perfectly onto block-based layouts.
  • Multi-Currency Plugins: Supports base currency conversions for deposits and balance payments.
  • Stripe Gateway: Out-of-the-box integration for auto-charging balances using Stripe card tokens.

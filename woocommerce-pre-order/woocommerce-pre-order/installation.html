Installation & Plugin Updates

Learn how to download, install, configure, and safely update the WooCommerce Pre-Order plugin on your WordPress site.

1. Installation via WordPress Dashboard

This is the recommended and easiest installation method:

  1. Download the ZIP File: Log into your Webkul account and download the wp-woocommerce-pre-order plugin ZIP file.

  2. Navigate to Plugins: Log into your WordPress admin panel and go to Plugins > Add New.

  3. Upload the Plugin: Click Upload Plugin at the top. Choose the downloaded ZIP file and click Install Now.

  4. Activate: Once the upload completes, click Activate Plugin.

2. Installation via FTP / SFTP

If you experience server upload limits, upload the plugin files directly:

  1. Extract the ZIP File: Extract the downloaded wp-woocommerce-pre-order.zip on your local computer. This creates a folder named wp-woocommerce-pre-order.
  2. Connect to your Server: Use an FTP client (such as FileZilla) to connect to your web host.
  3. Upload the Folder: Navigate to /wp-content/plugins/ and upload the extracted wp-woocommerce-pre-order folder.
  4. Activate: Go to Plugins > Installed Plugins in your WordPress dashboard, find "WooCommerce Pre-Order", and click Activate.

3. Module Translation

The WooCommerce Pre-Order plugin is localization-ready and can be translated into any language. Follow these steps to translate the interface:

  1. Locate translation template: The translation template file (.pot) is located in the plugin's /languages/ directory.
  2. Use Translation Tool: Open the .pot template file using a tool like Poedit or the Loco Translate plugin.
  3. Translate Strings: Translate the source strings to your target language.
  4. Save Files: Save the translation files with the correct locale extension:
    • .po file (e.g., woocommerce-pre-order-fr_FR.po for French)
    • .mo compiled translation file (e.g., woocommerce-pre-order-fr_FR.mo)
  5. Deployment Path: Upload the saved .po and .mo files to the standard WordPress languages directory:
    /wp-content/languages/plugins/
    This ensures that translation files are not overwritten when you update the plugin.

4. Module Activation & License Verification

To receive plugin updates and customer support directly inside your WordPress dashboard, activate your plugin license:

  1. Navigate to License Settings: Go to Plugins > Webkul License Manager or find the license activation tab in your plugin settings.
  2. Provide Credentials:
    • Purchase Code: Copy the unique purchase key from your Envato/Webkul account.
    • Registered Email: Enter the email address used during purchase.
  3. Activate: Click Activate License. A green success badge indicates successful verification.

For a detailed step-by-step walkthrough, please refer to the Webkul License Validator Guide.

5. Safe Update Procedures

Webkul regularly releases updates containing features, bug fixes, and performance improvements. Follow these guidelines to update safely:

Data Safety

All pre-order campaigns, subscriber lists, settings, and transaction records are stored securely in your website's database. Deleting the plugin files will not delete your pre-order configurations or customer history.

[!WARNING] Before performing any plugin updates, always take a complete backup of your database.

Update Workflow:

  1. Go to Plugins > Installed Plugins.
  2. Find WooCommerce Pre-Order and click Deactivate.
  3. Click Delete to remove the old version files (your database data remains safe).
  4. Upload the new version ZIP file via Plugins > Add New > Upload Plugin.
  5. Click Activate Plugin. The plugin will automatically run migration checks and apply database updates if required.

Pre-Order Cancellation Management

The WooCommerce Pre-Order plugin provides a complete, merchant-friendly Pre-Order Cancellation Request workflow. This system allows customers to request cancellations directly from their account dashboards while giving administrators full control to review, approve, automatically refund, or decline cancellation requests.

1. The Cancellation Request Workflow

Below is the visual workflow detailing how a customer cancellation request is routed and processed:

2. Administrator Settings (Days to Cancel)

Administrators can control which pre-orders are eligible for customer cancellation. Go to WooCommerce > Pre-Order List > Configuration > Days to Cancel tab to define the cancellation window:

  • Cancel Status: Toggle to enable or disable customer-initiated pre-order cancellation requests globally.
  • Cancel Before (Days): Enter the number of days before the product release date during which the customer can submit a cancellation request. If left empty or set to 0, the customer can request cancellation anytime up until the actual release.

3. Customer Cancellation Request Flow (Storefront)

Registered and guest customers can request cancellation from their respective pre-order lists:

  1. Locate Pre-Order: Navigate to My Account > Pre-Orders (registered customers) or the My Pre-Orders OTP portal (guests).

  2. Submit Request: In the pre-order table, click the Cancel Pre-Order button under the actions column.

  3. Provide Reason: A secure modal will appear. Enter a brief reason for requesting the cancellation, then click Submit Request.

  4. Pending Status: The customer's dashboard updates immediately to show a notice that the cancellation request has been submitted for review.

4. Processing Requests (Admin Dashboard)

Store administrators manage incoming cancellation requests under WooCommerce > Pre-Order List > Cancellation Requests:

The Cancellation Requests List

The dashboard table displays all pending, approved, and declined requests with their associated order numbers, product names, customer details, submission date, and status.

Reviewing a Request

To action a pending request, click the Review button under the order row. This displays a detailed audit screen including the customer's specified cancellation reason, original order totals, and refundable amount.

Approving a Cancellation and Refund

  1. On the review screen, click Approve & Refund.
  2. A confirmation dialog will appear. Optionally enter a private refund note to attach to the WooCommerce order, then click Approve & Refund.
  3. The system automatically cancels the pre-order and triggers a standard refund process for the pre-order deposit or full price paid.

Declining a Request

  1. Click the Decline Request button on the review screen.
  2. Provide a reason for the decline (e.g., "Cancellation request submitted past the allowed window").
  3. Click Decline Request. The pre-order remains active, and the customer receives an automated email notification with your reason.

[!NOTE] Automated refunds rely on the payment gateway used during the original checkout. For offline or check payments, the store admin must issue refunds manually, while the pre-order status will still update to "Cancelled" in the database.

My Pill Box

(Version 1.3.x) My Pill Box — also called the Chronic Disease Pill Organizer — lets customers save named groups of medicines ("family health folders") and re‑order them in a single click. It's ideal for repeat and long‑term medication.

Enable it on the Optional Features tab (Enable Chronic Disease Pill Organizer). Once on, a My Pill Box tab appears under My Account.

What a customer can do

Create a folder

  1. Go to My Account → My Pill Box.
  2. Enter a Folder Name — for example, "Father's Monthly Meds" or "Diabetes Kit".
  3. Select medicines using the searchable multi‑select ("Type or choose medicines…").
  4. Click Save My Pill Box.

Manage saved folders

Saved folders are listed in a table showing:

ColumnContents
Folder NameThe name the customer gave the folder
Medicines InsideThe medicines saved in that folder
Action1‑Click Buy and Delete buttons

1‑Click Buy

Clicking 1‑Click Buy loads all the medicines from that folder into the cart and takes the customer straight to checkout — turning a recurring multi‑item order into a single tap.

Delete

Removes a folder the customer no longer needs (with a confirmation prompt).

Why it's useful

  • Chronic conditions — patients on ongoing treatment re‑order the same set of medicines every month without hunting for each product.
  • Caregivers — someone managing medication for family members keeps a separate folder per person.
  • Faster repeat orders — fewer steps means fewer abandoned carts for your most loyal customers.

Works with gating

Pill Box is a convenience layer on top of normal shopping. If any medicine in a folder is prescription‑required, the usual upload and approval flow still applies at checkout — Pill Box doesn't bypass gating.
